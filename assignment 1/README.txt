- *_output.png: PNG output screenshot captured from the actual program output.

HOW TO RUN
1. Extract this ZIP folder.
2. Install Python 3.
3. Open a terminal in this folder.
4. Run: python Q01_frequency_reuse_strategies.py
5. Repeat for the required question number.

ACADEMIC NOTE
Monte Carlo examples use explicitly stated illustrative models and fixed random seeds.
Their outputs are software-generated example results, not field measurements. The assignment
requires actual validation before submission. Exact event blocking cannot be calculated because
the brief does not specify stadium channel allocation, sectors, arrival profile or neighbouring-cell spare capacity.
