MOBILE COMPUTING - ASSIGNMENT 3 (CO3)
Coding files and output screenshots for individual questions Q1-Q7.

Files:
- Q1_wireless_mobility.py: mobility scenarios, PDR and delay
- Q2_mobile_ip_registration.py: Mobile IP registration and packet tunnelling trace
- Q3_cellular_vs_adhoc.py: cellular/ad hoc comparison
- Q4_mobile_ip_healthcare_app.py: emergency healthcare application requirements
- Q5_dsdv_proactive_routing.py: DSDV route-table update demonstration
- Q6_aodv_reactive_routing.py: AODV RREQ/RREP/RERR trace
- Q7_emergency_network_design.py: emergency mesh network test cases

Run:
    python Q1_wireless_mobility.py
(replace the filename for Q2-Q7)

Dependencies:
    Python 3
    matplotlib (Q1 uses it to create a graph)

The screenshots folder contains one output screen for each question.
The outputs folder contains captured console output and CSV result files.

IMPORTANT:
The assignment document labels its completed lab-style values as illustrative, not measured
NS-2/NS-3/OMNeT++ output. These programs reproduce illustrative demonstration traces and
sample tables for learning and presentation. They are NOT actual packet-level network
simulations. If your faculty requires real simulator evidence, replace these with exported
NS-2/NS-3/OMNeT++ results and explain the assumptions in your viva.
